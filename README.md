
# 🎬 MovieVault

**MovieVault** is a Python-based movie watchlist and rating tracker that helps users organize their movie collections, track watched movies, manage ratings, and explore their favorite films.

## ✨ Features

- ➕ Add movies with title, genre, year, and rating
- 📋 View your complete movie collection
- 🔍 Search movies by title
- ✅ Mark movies as watched or unwatched
- ⭐ Update movie ratings
- 🏆 Display top-rated movies
- 📊 View collection statistics
- 🎭 Filter movies by genre
- 🗑️ Delete movies from your collection
- 💾 Automatically save data using JSON

## 🛠️ Technologies Used

- Python 3
- JSON
- File Handling
- Lists and Dictionaries
- Functions
- Exception Handling

## ⚙️ Installation and Usage

### 1. Clone the repository

```bash
git clone https://github.com/hxrshits/movie-vault.git
```

### 2. Navigate to the project

```bash
cd movie-vault
```

### 3. Run the application

```bash
python3 movie_vault.py
```

## 💾 Data Storage

MovieVault uses a local JSON file (`movies.json`) to store movie information.

Your movie collection remains saved even after closing the application.
